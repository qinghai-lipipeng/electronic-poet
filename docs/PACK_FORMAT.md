# 词库包格式（挂载语言资源）

电子诗人的全部语言资源——**语法模板、词库、韵部、元信息**——都位于挂载目录中的一个个“词库包”里，不编译进程序本体，可随时整体替换、增删或手工编辑。

## 目录结构

```text
<pack-id>/
├── manifest.conf        # 必需，包元信息
├── grammar/
│   ├── modern.txt       # 必需，正文句式模板（文件名任意，可多个 .txt）
│   └── title.txt        # 可选，标题模板（文件名必须是 title）
├── lexicon/
│   ├── MM.txt           # 必需（至少一个），词库，文件名=占位符代码
│   ├── DD.txt
│   ├── DJ.txt
│   ├── XX.txt
│   └── TT.txt
└── rhyme/               # 可选，韵部
    ├── jiang.txt
    └── zhong.txt
```

## manifest.conf

简单的 `key = value`，`#` 开头为注释：

```conf
id = classic                 # 必需，包的唯一标识（也用于导入时的目录名）
name = 电子诗人·经典词库       # 显示名称
version = 1.0
author = ...
description = ...
```

## 语法模板 grammar/*.txt

每行一条模板，规则：

- **连续两个 ASCII 大写字母**构成占位符，如 `MM在DD`；
- 空行、`#` 开头的行为注释；行内可用 ` # ` 写注释；
- 重复出现的模板权重更高；也可在行尾用 `<TAB>权重` 显式指定；
- `title.txt` 中的模板用于生成标题，其余 `.txt` 用于正文。

示例：

```text
MM在DD
XX的MM在DD
我面对着XX的MM和XX的MM
MMDJMM
TTXX的MM
从MM到MM
让MM变得XX吧
```

## 词库 lexicon/<CODE>.txt

文件名是两个大写字母的占位符代码，与模板中的占位符对应。每行一个词：

- 重复出现的词权重更高；也可 `词<TAB>权重`；
- `#` 注释；词中若需 `#`，写成 `\#`。

经典代码约定（可自定义，模板与词库一致即可）：

| 代码 | 含义 | 示例 |
|---|---|---|
| `MM` | 名词 / 意象 | 月亮、灯塔、荒原 |
| `DD` | 自动词（不及物） | 飞翔、游荡、燃烧 |
| `DJ` | 他动词（及物） | 拥抱、追逐、照亮 |
| `XX` | 修饰语（形容词 / 形状 / 颜色） | 金色、荒凉、圆柱形 |
| `TT` | 叹词 | 啊！、噢！、咦！ |

## 韵部 rhyme/<ID>.txt

文件名是韵部 id，每行 `CODE=词`，表示该韵部中可用于某占位符的词：

```text
# jiang 辙
DD=飞翔
DD=游荡
MM=光芒
```

押韵时，模板**句尾的占位符**从对应韵部取词。因此用于押韵的模板必须以占位符结尾（如 `MM在DD`）。

韵部通常不需要手工整理：离线工具 `pack-tools rhyme <pack目录>` 会按末字拼音自动归入汉语“十三辙”：

| 辙 id | 名称 | 韵母 |
|---|---|---|
| fa | 发花 | a / ia / ua |
| suo | 梭波 | o / e / uo |
| mie | 乜斜 | ie / üe |
| yi | 一七 | i / ü / er |
| gu | 姑苏 | u |
| huai | 怀来 | ai / uai |
| hui | 灰堆 | ei / ui |
| yao | 遥条 | ao / iao |
| you | 由求 | ou / iu |
| yan | 言前 | an / ian / uan / üan |
| ren | 人辰 | en / in / un / ün |
| jiang | 江阳 | ang / iang / uang |
| zhong | 中东 | eng / ing / ong / iong / ueng |

## 运行时行为

- 应用在进入“词库管理”时重新扫描挂载目录，新增包立即可见；
- 模板引用了缺失或为空的词库时，该模板自动不可用，其余模板照常工作；
- 开启押韵但没有任何可用韵部时，自动回退为不押韵并给出提示。
